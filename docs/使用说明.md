# WirelessDAP 2.2

2026-11-01 · Windows x64 · ESP32-P4＋C6

## 启动

双击本目录的 WirelessDAP.exe。可以只复制这个 EXE 到其他可写目录使用，所需 OpenOCD、SSH 客户端和 Keil 插件已内嵌。系统要求 Windows 10 1809 或更新版本。上位机由 C++ 编写，运行时无需 Python、MSYS2 或另装 VC 运行库。

界面采用白色卡片、浅灰背景和黑色主按钮。左侧切换九个工作区，主区域显示参数与数据记录。启动后进入 STM32 烧录与调试页，CMSIS-DAP 和 ST-LINK 两个烧录后端可直接选择。SSH 终端嵌入同一窗口。

## 连接与供电

- USB 有线时选择 USB 有线，点击扫描设备并连接。端口号由 Windows 分配，当前实板应用端口为 COM16。
- 蓝牙时选择蓝牙 BLE，扫描并连接 WirelessDAP。使用 BLE GATT，无需蓝牙虚拟串口。
- Wi-Fi 连接热点 WirelessDAP，热点密码为 CHANGE-ME-12345，软件内填写 192.168.4.1。当前固件使用热点模式。此次按用户要求保留现有 WLAN，Wi-Fi 实板验收留待后续进行。
- J1-3 VREF 接目标板实际 3.3V 电源轨，作为输入参考。J1-21 为受控 3.3V 电源输出。J1-23 为硬件直出的辅助 5V。
- 当前 H743 接线为 J1-21 → H743 的 3.3V，H743 的 3.3V → J1-3，J1-4 → GND。H743 的 USB 保持拔出，由调试器供电。
- 点击 3.3V 开给目标供电。外部供电的目标只接 VREF 与信号地，J1-21 留空。断开调试器会关闭受控 3.3V 和接口，J1-23 的 5V 由硬件决定。
- GPIO 信号使用 3.3V 电平，VREF 允许检查范围为 2.7–3.6V。

完整的 24 针定义见随附 J1_24Pin接口表.csv。

## 多接口操作

从左侧选择接口，设置参数后点击启用接口。切换页面保留已开启的接口，停用接口只关闭当前一路。勾选多路接收，UART1、UART2、RS485 和 CAN 会持续轮询并把反馈写到各自页面。发送数据和接收记录均支持复制粘贴，记录可保存为 UTF-8 文本。

- UART1 使用 J1-5 TX 和 J1-6 RX，UART2 使用 J1-7 TX 和 J1-8 RX。TX 接对方 RX，RX 接对方 TX。
- RS485 使用 J1-17 A 和 J1-18 B，板上收发器自动控制半双工方向。
- I²C 主机使用 J1-9 SDA 和 J1-10 SCL，支持 7 位地址、扫描和重复起始读写。
- SPI 主机使用 J1-11 SCK、12 MOSI、13 MISO、14 CS，支持四种时钟模式、MSB/LSB 位序，单次传输保持片选。
- CAN 使用 J1-15 CANH 和 J1-16 CANL，支持经典 CAN 的标准帧、扩展帧、远程帧，以及监听和自测回环。
- GND 位于 J1-4、19、20、22、24。CAN 和 RS485 的终端电阻按实际总线两端配置。

## 自研软件烧录 STM32

1. J1-1 接目标 SWDIO，J1-2 接 SWCLK，J1-3 接目标 3.3V 电源轨，J1-4 接 GND。
2. 在 STM32 烧录页选择 CMSIS-DAP 或 ST-LINK 后端，再选择自动识别或具体 STM32 系列，点击识别目标。
3. 粘贴固件路径或将 BIN、HEX、ELF、AXF 文件拖入窗口。BIN 需要填写真实烧录地址，其他格式按文件内地址处理。
4. 点击烧录并读回校验。成功结果来自实际读取比较。校验后运行可使用软件复位启动目标。

已内置 22 个 STM32 系列的离线配置，实际擦写和读回验收使用 STM32H743VIT6。Flash 更新会擦除镜像涉及的完整扇区，保留数据应放在独立扇区或提前备份。受保护芯片、特殊安全配置和外部 Flash 需要对应支持配置。当前板未引出目标 NRST，连接方式使用 SWD 和软件复位。

## Keil 直接下载

1. 在 STM32 烧录页填写 Keil 安装目录，点击配置插件。安装会备份原 DLL 和 TOOLS.INI。
2. 在 Keil 项目的 Debug 设置中选择 elaphureLink Debugger。
3. 选择 SWD、100kHz、SYSRESETREQ，取消 Reset after Connect。H743 的 Flash 算法选择 STM32H7x_2048，并使用该目标实际 RAM 配置。
4. 在本软件连接调试器、打开目标供电并开启 Keil 无线桥，保持窗口连接，再由 Keil 下载。

USB 和蓝牙两种连接均已在 Keil 实际完成 H743 擦除、编程和 Verify OK。标准 USB CMSIS-DAP HID 枚举及第三方工具读取 H743 也已通过。USB 和 BLE 的单步与执行断点均已完成实测。ST-LINK 共享服务的使用方式见下一节。

## ST-LINK 与 ST 官方软件

软件内选择 ST-LINK 后端后，识别、擦写和校验通过 ST-LINK 命令进入 ESP 的 SWD 接口。该后端与 CMSIS-DAP 共用当前 USB、蓝牙或 Wi-Fi 连接。

使用 STM32CubeProgrammer 时按以下步骤操作。

1. 在本软件连接 ESP，确认目标供电和 VREF 正常。
2. 在 STM32 烧录页点击 ST-LINK 兼容桥，保持本窗口连接。
3. 在 STM32CubeProgrammer 中选择 ST-LINK、SWD，开启 Shared 模式，将 ST-LINK server 端口设为 7185。
4. 连接方式选择 Hotplug，SWD 频率设为 100kHz，再刷新探针并连接。桥接探针序列号为 57445354E83DC1D250420001。
5. 可使用官方工具识别芯片、下载及校验。结束后关闭官方工具连接，再关闭兼容桥。

命令行示例适用于已安装的 STM32CubeProgrammer。

```
STM32_Programmer_CLI.exe -c port=SWD shared tcpport=7185 mode=HOTPLUG freq=100 -w "firmware.bin" 0x08000000 -v
```

此功能通过本机 ST-LINK Server API3 兼容桥接入官方软件。ESP 的 USB 枚举仍采用 CMSIS-DAP HID＋CDC。Keil 桥与 ST-LINK 桥分别占用同一目标调试接口，使用时选择其中一个。打开桥接前先完成目标供电设置。J1 其他已开启接口继续独立运行。

ST 官方工具实测版本为 STM32CubeProgrammer 2.19.0。USB 和蓝牙均已完成 H743 下载、官方校验、独立读回及原扇区恢复。蓝牙连接在 Windows 11 上申请高吞吐参数，并在断开后释放。Windows 10 使用系统协商参数。无线传输速度由实际连接状态决定。Windows 参数接口见 [Microsoft 官方说明](https://learn.microsoft.com/en-us/uwp/api/windows.devices.bluetooth.bluetoothledevice.requestpreferredconnectionparameters)。

## SSH 远程终端

SSH 按普通电脑到远程主机的客户端实现，可独立于 ESP 连接使用。填写主机、端口和用户名后点击连接 SSH。使用密钥时可直接粘贴 Windows“复制文件地址”得到的 OpenSSH 私钥路径，加密私钥的口令也在内嵌终端中输入。使用密码时在终端认证提示处输入。首次连接按实际主机指纹确认，主机密钥发生变化时客户端会拒绝连接。

终端支持 UTF-8、ANSI 光标控制、方向键、功能键、Ctrl+C、鼠标选取、复制、粘贴和滚动历史。密码输入不回显，应用不保存密码。关闭会话或主窗口会结束对应 SSH 子进程。SSH 会话不占用 J1 接口。

## 固件与交付内容

- WirelessDAP.exe 为可单独复制运行的上位机。
- firmware/p4_rev3 为本轮已烧入 P4 v3.2 并完成 USB、蓝牙回归的镜像，包含 CAN 长度、I²C 空闲等待与固定执行核心修正。启动后使用标准 CMSIS-DAP HID＋CDC，等待数秒完成枚举。
- 需要维护固件时，按住 BOOT，按一下 RESET，再松开 BOOT 进入下载模式。镜像地址和参数见 firmware/p4_rev3/flash_args。
- 2.2 复用已经烧入的 P4 和 C6 固件。此次 ST-LINK 与 UI 更新在上位机完成。
- WirelessDAP-source.zip 包含上位机、P4 固件和本次修改源码。
- OpenOCD-source.zip 包含对应引擎源码、TCP 与 ST-LINK 驱动修改、libusb 对应源码及重建说明。
- evidence 包含实板和软件测试日志，验收结果见 验收记录.txt。
- 第三方版本和许可见 THIRD_PARTY.txt 与 licenses。内嵌 SSH 使用上游 10.4.0.0p1-Preview 版本。

运行自检可使用 WirelessDAP.exe --self-test，结果生成在 EXE 旁的 self-test.txt。自检覆盖离线逻辑，实板证据另行列在验收记录中。
