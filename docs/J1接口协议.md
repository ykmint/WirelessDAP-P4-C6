# J1 接口协议与使用说明

2026-10-30。仍使用 WD v1 帧和已有鉴权，Wi-Fi TCP 6123 与 BLE 共用同一实现。多字节整数为小端。响应首字节为状态；0 成功，1 未鉴权，2 忙，3 参数错误，4 电源保护，5 后接 UTF-8 驱动错误文本。状态5仅报告当前事务错误，保持连接和其他接口运行；通信或鉴权错误关闭会话。总线操作不自动重放。

## 功能与针脚

| 功能 | J1 | 功能范围 |
|---|---|---|
| SWD | 1 SWDIO、2 SWCLK | 原主窗口烧录功能保留 |
| VREF | 3 | 目标电压采样；TTL、I²C、SPI 要求 2.7–3.6V |
| UART1 | 5 TX、6 RX | 300–1000000 baud，5–8 数据位，无/奇/偶校验，1/2 停止位 |
| UART2 | 7 TX、8 RX | 与 UART1 相同 |
| I²C | 9 SDA、10 SCL | 主机，7 位地址 0x08–0x77，10–400kHz，扫描、读、写、重复起始读写 |
| SPI | 11 SCK、12 MOSI、13 MISO、14 CS | 主机，Mode 0–3，MSB/LSB，10kHz–10MHz，CS 低有效、单次事务连续片选 |
| CAN | 15 H、16 L | 经典 CAN，标准/扩展数据帧及远程帧，正常/监听/自测回环，不支持 CAN FD |
| RS485 | 17 A、18 B | 半双工 UART，自动 DE/RE 方向控制 |
| GND | 4、19、20、22、24 | 共地 |
| TARGET_PWR | 21 | 受控 3.3V；默认关闭，断线/关闭界面/故障关闭 |
| 5V | 23 | 硬件直出，无软件开关或独立测量通道 |

只连接 3.3V TTL 目标。VREF 接目标实际电源，不能把 5V 接到 VREF。已有外部电源时不接 J1-21。I²C/SPI 上拉在板上接 VREF，启用接口前必须提供此参考。CAN/RS485 的终端电阻按实际总线安装；默认不假定已安装。

六路接口可同时启用，每路独立配置、启停与接收缓冲。UART1/UART2/RS485/CAN 在后台接收，SPI/I²C 可交叉执行事务。无线命令按序执行，硬件接收并行运行。上位机主窗口和接口窗口使用独立会话，切换窗口连接前先断开原会话。接口断线会释放数字引脚，RS485 进入接收，CAN TX 保持隐性电平。TTL VREF 丢失关闭 UART1/UART2/I²C/SPI；其他接口继续按本地供电运行，整板电源故障仍触发保护。UART 接收队列 4096 字节；CAN 接收队列 64 帧，使用自动接收及时读取。rx_errors 为 UART 溢出/帧/校验事件数或 CAN 软件接收丢帧数，不是字节数。无线吞吐有限，不能保证连续高速流无损；日志会提供溢出计数。

## 操作码

- 0x10 / 16：能力查询，无载荷；返回 j1_api=2、parallel=true、模式、240 字节上限。
- 0x11 / 17：配置，固定 8 字节：mode(u8)、rate(u32)、a(u8)、b(u8)、c(u8)。mode 0关闭全部，其余模式只配置指定接口、不关闭其他接口：1 UART1、2 UART2、3 RS485、4 I²C、5 SPI、6 CAN。UART/485 a=0无/1奇/2偶、b=5..8、c=1/2。I²C a/b/c=0。SPI a=0..3、b=0MSB/1LSB、c=0。CAN a=0正常/1监听/2自测、b/c=0；速率支持10k/20k/50k/100k/125k/250k/500k/800k/1M。
- 0x12 / 18：发送/事务。载荷首字节为接口编号1–6，其后为事务数据：UART/485 原始字节，1–240；低速下单次线速时间限制250ms。SPI 1–240字节全双工，返回等长读入数据。I²C 为 address(u8)、read_count(u8)、0–240写入字节；同时写读使用重复起始，返回 read_count 字节。CAN 为 id(u32)、flags(u8，bit0扩展、bit1远程)、DLC(u8)、数据(0–8)；远程帧无数据，DLC仍有效。CAN 返回成功表示收到驱动成功完成事件，自测模式不要求外部 ACK；失败不自动重发。
- 0x13 / 19：接收，载荷为接口编号(u8)。UART/485 返回0–240字节。CAN 返回若干14字节记录：id(u32)、flags(u8)、DLC(u8)、固定8字节数据(远程帧补零)。
- 0x14 / 20：I²C 扫描，载荷为4(u8)、start/end各u8，单次最多16地址，返回有ACK的7位地址列表。
- 0x15 / 21：接口状态，无载荷返回 enabled_mask（bit1–6对应接口1–6）、parallel；携带接口编号(u8)返回该接口 mode、rate、rx_errors、can_state、can_tx_errors、can_rx_errors、bus_errors。
- 0x16 / 22：关闭指定接口，载荷为接口编号(u8)，其他接口保持运行。
- 原 0x03：VREF/电源故障状态；原 0x04：0/1关闭/开启受控3.3V。关闭电源也关闭活动接口。

## 原生上位机

主窗口左侧「接口调试」打开独立窗口；也可使用 `WirelessDAP.exe --interfaces`。保持原 Wi-Fi，选择 BLE、扫描、连接。接口窗口连接只检查调试器，不要求 STM32 连接。选择接口、速率及格式后点「应用配置」，逐路启用所需接口；切换下拉框不会停用已启用接口，「关闭当前」仅关闭所选接口。自动接收轮询所有已启用 UART/485/CAN，日志注明来源。UART/485 自动接收；HEX 输入示例 `01 02 A0 FF`，也支持 UTF-8 文本和追加 CRLF。I²C 填写7位HEX地址和读取字节数；SPI 读取长度大于发送长度时补0xFF产生时钟。CAN 填写HEX ID、帧类型、数据，远程帧使用读取字节框作为DLC。

界面数据支持标准复制粘贴，记录可保存UTF-8文本。UART 溢出与校验错误可在状态中查看；空载 I²C NACK 等事务错误会显示原因并保留其他接口连接，不盲目重发。无线吞吐由所有接口共享，请根据实际吞吐调整速率并观察溢出计数。

这些是总线通信功能，不会自动识别任意目标 Bootloader；当前固件烧录通道仍为 SWD。
