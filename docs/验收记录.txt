WirelessDAP 2.2 验收记录
2026-11-01

本轮交付
原生 C++ 单 EXE。左侧九个工作区、白色卡片、浅灰背景、黑色主按钮。
STM32 烧录页直接选择 CMSIS-DAP 或 ST-LINK，保留 Keil 与内嵌 SSH。
新增 ST-LINK Server API3 兼容桥，供自研软件和 STM32CubeProgrammer 使用。
官方工具通过本机 Shared 服务接入。ESP USB 继续枚举为 CMSIS-DAP HID＋CDC。
P4 和 C6 板上固件沿用已验收版本，本轮更新上位机。

本轮实板验收
目标为 STM32H743VIT6，Flash 2MiB。
1. STM32CubeProgrammer 2.19.0 经 USB ST-LINK 桥完成写入和官方校验。
2. 同一官方工具经蓝牙 ST-LINK 桥完成写入和官方校验。
3. 软件内置 OpenOCD 的 ST-LINK 后端经 USB 完成烧录和逐字节读回校验。
4. 同一软件内置后端经蓝牙完成烧录和逐字节读回校验。
5. 上述写入测试均先备份 0x081E0000 的 128KiB 扇区，成功后独立读回测试图案，再恢复原扇区并校验。
6. USB 和蓝牙分别完成 90 秒并发复测，每组 26 轮六接口操作。
   UART1 两个方向每组各 2496 字节一致，UART 接收错误为 0。
   同时执行 SPI 驱动传输、CAN 内部回环、空 I²C 总线扫描、RS485/UART2 发送。
   同时通过 ST-LINK SWD 读取 H743 CPUID，USB 89 次，蓝牙 83 次。
7. 测试结束后重新读取完整 2MiB Flash，并与最初备份逐字节比较，完全一致。

修正记录
ST-LINK Server API3 的 OPEN 请求包含附加标志字段，按 12 字节处理。
实现 ST-LINK 直接调试寄存器、存储器、核心寄存器和批量存储器操作。
非法或不完整写入在操作目标前拒绝，批量结果按客户端分别保存。
USB 模式下官方工具与内置引擎使用一致的桥接实现。
蓝牙请求 Windows 11 高吞吐连接参数，1020 字节算法块的实测耗时从约 3.9 秒降到约 1.3 秒。
该优化解决了官方工具算法装载超时。断开连接时释放参数请求。
界面增加 VREF 检查、两种烧录后端选择和 ST-LINK 共享桥入口，统一输入框样式并使日志自动换行。
