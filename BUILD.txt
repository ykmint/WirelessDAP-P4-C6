Native application build
Use a current Visual Studio MSVC x64 C++ toolchain and Windows SDK.
Open an x64 Native Tools Command Prompt for Visual Studio before building.
Run native/build.cmd from the source root. Output is native/build/WirelessDAP-dev.exe.
The archive includes native/build/payload, so rebuilding the delivered application does not require downloading its runtime components.
Run the resulting EXE with --self-test. The report is written beside the EXE.

P4 firmware build
Use the project's ESP-IDF 6.1 environment and esp32p4 target.
The included sdkconfig is for P4 silicon rev3 and 16MB flash.
Run idf.py build in firmware after activating ESP-IDF.
Dependency versions are recorded in firmware/dependencies.lock.
The existing C6 image is retained in firmware/main/c6_image.bin.

Validation sources are in native/tests and native/src/ssh_tests.cpp.
Hardware tests refer to this user's specific ports and H743 test sector. Read and adapt their explicit fixture settings before using a different board.
The repository uses CHANGE-ME credential placeholders. Configure matching firmware and native/src/board_config.h values before deployment.
